# Student Management System

A console-based student management system written in Python — an object-oriented programming exercise. Students and enrolment status live in memory while the program runs.

## Features

- `Student` class with private id, name, department and enrolment status
- `StudentDatabase` class that stores students and finds them by id
- Enroll / drop students, and view all students with their enrolment status
- 3 sample students included (Khalid — CSE, Ayesha — EEE, Tanvir — BBA)

## Run it

```bash
python Student_management_system.py
```

Menu: `1.` View All Students · `2.` Enroll Student · `3.` Drop Student · `4.` Exit

## Tech stack

Python 3 (standard library only — no dependencies)
